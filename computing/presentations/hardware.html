Computer Hardware

Meet the physical parts inside and around a computer.

A computer is a team of components. Each part has a job.
THREE SEEDS · COMPUTING · 02

Hardware means things you can touch

Hardware is the physical equipment: the screen, keyboard, mouse, processor, memory and storage.

Software is different: it is the programs and instructions that run on the hardware.
THREE SEEDS · COMPUTING · 03

The processor: the instruction engine

The CPU follows instructions, performs calculations and coordinates work. It repeatedly fetches, decodes and executes instructions.

A faster CPU can complete many tasks quickly, but performance also depends on memory, storage and cooling.
THREE SEEDS · COMPUTING · 04

Memory and storage are different

RAM is fast, temporary working space. Storage keeps files and apps when the computer is switched off.

Try this: a photo saved for next week belongs in storage, not RAM.
THREE SEEDS · COMPUTING · 05

Input, processing and output

Input devices send information in. The processor works with it. Output devices show or play the result.

Keyboard and microphone are inputs. A monitor and speakers are outputs.

Put the parts together

A computer needs components working together: CPU, RAM, storage, input, output and a power source.
