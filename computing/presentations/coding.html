Algorithms

An algorithm is a clear sequence of steps for solving a problem.

A recipe, directions and a sorting method can all be algorithms.

STEP BY STEP
THREE SEEDS · COMPUTING · 03

Sequence

A program runs instructions in order. Changing the order can change the result.

A sensible sequence helps a computer complete a task correctly.

ORDER MATTERS
THREE SEEDS · COMPUTING · 04

Loops

A loop repeats instructions, so you do not need to write the same steps again.

A repeat loop can move a character forward ten times or draw a shape.

REPEAT
THREE SEEDS · COMPUTING · 05

Selection

Selection lets a program choose what to do based on a condition.

IF it is raining, THEN take an umbrella. ELSE wear a sun hat.

IF / ELSE
THREE SEEDS · COMPUTING · 06

Debugging

Debugging means finding and fixing mistakes in a program.

Test one change at a time, read error messages and check each step.

FIND + FIX
